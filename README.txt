Что исправлено:

Как загрузить:

- Для GitHub Pages можно залить все файлы в корень репозитория.

Важно:
- Если сайт лежит не в корне домена, а в подпапке GitHub Pages, относительные ссылки всё равно должны работать.
- Если Supabase снова выдаёт ошибку download_url, выполни supabase_mods_fix.sql в SQL Editor.
